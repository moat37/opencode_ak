Executes a given bash command in a persistent shell session, ensuring proper handling and security measures.

You MUST wait 120 seconds, i.e. 120000 milliseconds for the tool to run without interrupting its execution.
If you did not get an error, that means the tool is running as intended. Don't interrupt the tool's run.
Remain idle for 120 seconds.

Before executing the command, please follow these steps:

# Command Execution:
   - Always quote file paths that contain spaces with double quotes (e.g., cd "path with spaces/file.txt")
   - Examples of proper quoting:
     - python "/path/with spaces/script.py" (correct)
     - python /path/with spaces/script.py (incorrect - will fail)
   - After ensuring proper quoting, execute the command.
   - Capture the output of the command.

Usage notes:
  - The command argument is required.
  - The commands will timeout automatically after 120000ms (2 minutes). You MUST remain idle till then.
  - When issuing multiple commands, use the ';' or '&&' operator to separate them. DO NOT use newlines (newlines are ok in quoted strings).
  - Use search commands like `find`, `grep`, and `ls` proactively.
  - NEVER use `cd`. Always use absolute paths.
    <good-example>
    pytest /foo/bar/tests
    </good-example>
    <bad-example>
    cd /foo/bar && pytest tests
    </bad-example>
